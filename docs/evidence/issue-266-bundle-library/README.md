## AC5 — bundle-size and launch-cost delta (measured)

Resource size, measured by `verify-assets.py` from git blobs (base) and the
working tree (head): 36 PNGs + catalog = 144 093 B → 260 PNGs + catalog =
1 161 313 B, i.e. **+1 017 220 B (≈ 0.97 MiB)** for 112 additional identities
and 5 additional category marks. Xcode copies that art flat into `Morsel.app`,
so the built-product A/B swaps the same `*-{paper,night}-64.png` files plus
`catalog.json` in the product (see below).

Cost: `FoodLibraryCostTests.testCatalogLoadAndInitialTodayRenderingCost` loads
`FoodArtworkCatalog.bundled` 31× and mounts the real `TodayView` 11×, printing
`ISSUE266_COST`. Head (130 identities, `.lane-logs/resume-native-focused.log`):
catalog load 0.62–0.77 ms (median ≈ 0.67 ms); Today mount+draw 61.6–87.9 ms
(first iteration 274.6 ms is the one-off warm-up). The baseline (18 identities)
and the head were then re-run back-to-back with the SAME compiled app and the
same `test-without-building` command, swapping only the built product's bundled
art set and restoring it byte-exactly:

| Resource set | art files in built app | art bytes in built app | catalog load, warm median | Today mount+draw, warm median | raw exit |
|---|---|---|---|---|---|
| base 6f3199e (18 identities) | 37 | 144 093 B | 0.120 ms (0.116–0.352) | 65.3 ms (57.6–68.7) | 0 |
| head (130 identities), same command | 261 | 1 276 919 B | 0.619 ms (0.600–0.899) | 51.3 ms (47.1–60.7) | 0 |
| **delta** | +224 | **+1 132 826 B (≈ 1.08 MiB)** | **+0.499 ms** | **−14.0 ms (run-to-run noise, not a regression)** | — |
| head (130), focused run for context | 261 | 1 276 919 B | 0.674 ms (0.616–0.747) | 76.3 ms (61.6–87.9) | 0 |

So: ~1.1 MiB more in the built product buys 112 more identities and 5 more
category marks, catalog load stays sub-millisecond (the only measurable cost),
and the Today mount/draw time moved inside its run-to-run spread.


Method and raw logs: `.lane-tools/cost-ab.py` →
`.lane-logs/resume-native-baseline-cost.log` (restore proven by per-file SHA-256
inventory equality), `.lane-logs/resume-native-head-cost.log`; parsed samples and
medians in `cost-ab.json`.

No repo-documented launch-time budget exists to compare against
(`rg -n 'budget' docs/*.md` returns only unrelated storage/byte budgets), and a
`simctl launch` wall time measures process spawn, not first paint — so no
"launch ms" number is claimed here. The app itself launches and paints on the
lane simulator (the full unfiltered native invocation installs, launches and
mounts the real `TodayView`).
